# Privacy Policy — Thornfield Google Workspace Assistant

_Last updated: 12 October 2026_

## 1. Scope

This policy covers the Thornfield Google Workspace Assistant, a private integration operated by Thornfield Industries for internal use.

## 2. Data accessed

The application accesses only the Google account data that the account holder authorises on Google's consent screen. The permissions requested are shown on that screen.

## 3. How data is used

Google user data is used only to carry out tasks requested by the account holder. It is not used for advertising, or for any purpose unrelated to the account holder's request.

## 4. Storage

Authorisation credentials are stored on the operator's own systems, with restricted access. Google user data is processed to complete the requested task and is not retained by the application afterwards.

## 5. Sharing

Google user data is not sold or rented, and is not shared with third parties except service providers, including AI service providers, that process it solely to carry out the account holder's request.

## 6. Limited Use

The application's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. Google user data is not used to develop, improve or train generalised AI or machine-learning models.

## 7. Revocation

Access can be revoked at any time from the Google Account's [third-party connections page](https://myaccount.google.com/connections).

## 8. Contact

Please raise any enquiry as an issue on [this repository](https://github.com/thornfield-industries/legal/issues).

## 9. Changes

Changes to this policy are published on this page, with the date above updated.
